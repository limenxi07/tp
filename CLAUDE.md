# Claude Code

The rules for this repository are in `AGENTS.md`, imported above. They apply to every commit and PR you make here.
Keep commits authored by the configured git user, with no `Co-Authored-By` or Claude mention, and never push or open a PR
without the user's go-ahead.

Before committing a behavior change, search `docs/` for the old message text, command word, and class names, and update
every DG section that still describes the old behavior: implementation notes, use cases, manual testing, and diagrams
(`AGENTS.md` section 7).
